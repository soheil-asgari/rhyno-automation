2. **Implement Persian Digit Normalization in Controller (`HumanCapitalController.cs`):**
   - Add a helper method to convert Persian/Arabic unicode digits to standard ASCII English digits:
     ```csharp
     private static string? NormalizePersianDigits(string? input)
     {
         if (string.IsNullOrWhiteSpace(input)) return input;
         return input.Replace('۰', '0').Replace('۱', '1').Replace('۲', '2')
                     .Replace('۳', '3').Replace('۴', '4').Replace('۵', '5')
                     .Replace('۶', '6').Replace('۷', '7').Replace('۸', '8')
                     .Replace('۹', '9');
     }
     ```
   - Add a Jalali-to-Gregorian parser method using `System.Globalization.PersianCalendar`:
     ```csharp
     private static DateTime? ParseJalaliToGregorian(string? jalaliStr)
     {
         var normalized = NormalizePersianDigits(jalaliStr);
         if (string.IsNullOrWhiteSpace(normalized)) return null;

         var parts = normalized.Replace('/', '-').Split('-');
         if (parts.Length == 3 &&
             int.TryParse(parts[0], out int year) &&
             int.TryParse(parts[1], out int month) &&
             int.TryParse(parts[2], out int day))
         {
             var pc = new System.Globalization.PersianCalendar();
             return pc.ToDateTime(year, month, day, 0, 0, 0, 0);
         }
         return null;
     }
     ```
3. **Map Dates Before Database Save:**
   - In `[HttpPost] Create`, map the string properties from `HumanCapitalCreateVM` to the entity's `DateTime?` properties using `ParseJalaliToGregorian(...)` before calling `_context.SaveChangesAsync()`.
