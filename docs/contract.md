# ماژول قرارداد (Contract Module)

## 1. مدیریت پایه قراردادها (CRUD)

### 1.1. موجودیت‌های اصلی
| موجودیت | توضیح |
|---|---|
| **`Contract`** | هسته اصلی ماژول — شامل اطلاعات کامل قرارداد |
| **`ContractAmendment`** | اصلاحیه / الحاقیه / تمدید قرارداد |
| **`ContractPayment`** | ردیف پرداخت‌های انجام شده |
| **`ContractAttachment`** | فایل‌های پیوست نسخه‌بندی شده |
| **`ContractAttachmentVersion`** | نسخه‌های مختلف یک فایل پیوست |
| **`ContractAuditLog`** | لاگ تغییرات و رویدادهای قرارداد |
| **`ContractTemplate`** | قالب‌های HTML قرارداد برای تولید سند |
| **`ContractTypeField`** | فیلدهای پویا (EAV) بر اساس نوع قرارداد |
| **`ContractFieldValue`** | مقادیر فیلدهای پویا برای هر قرارداد |
| **`ContractGuarantee`** | ضمانت‌نامه / تضمین / کسر وجه تضمین |
| **`ContractPaymentSchedule`** | برنامه زمان‌بندی پرداخت اقساطی |
| **`ContractSignatureRequest`** | درخواست امضای الکترونیکی |
| **`ContractSignatureSigner`** | امضاکننده درخواست امضا |
| **`ContractUserSetting`** | تنظیمات کاربری ماژول قرارداد |
| **`AutoRenewalLog`** | لاگ تمدید خودکار |
| **`ContractApprovalRequest`** | درخواست تایید اصلاحیه |

### 1.2. عملیات‌های پایه
- **ایجاد (Create):** فرم چندبخشی شامل اطلاعات پایه، طرف قرارداد، تاریخ‌ها، مبالغ، فیلدهای پویا، انتخاب قالب، تنظیمات تمدید خودکار
- **ویرایش (Edit):** ویرایش کامل قرارداد با اعتبارسنجی فیلدهای پویا و دسترسی RLS
- **نمایش جزئیات (Details):** نمای کامل شامل اطلاعات، پرداخت‌ها، پیوست‌ها، اصلاحیه‌ها، لاگ‌ها، چرخه عمر و گام‌های زندگی
- **حذف (Delete):** حذف قرارداد با بررسی دسترسی
- **فهرست (Index):** صفحه فهرست با جستجو، فیلتر، مرتب‌سازی و صفحه‌بندی

### 1.3. وضعیت‌های قرارداد
10 وضعیت تعریف شده:
- `پیش‌نویس (Draft)` — `در انتظار تایید (PendingApproval)` — `فعال (Active)` — `در شرف انقضا (ExpiringSoon)` — `معلق (Suspended)` — `منقضی شده (Expired)` — `تکمیل شده (Completed)` — `لغو شده (Cancelled)` — `فسخ شده (Terminated)` — `بایگانی شده (Archived)`

### 1.4. انواع قرارداد
10 نوع پیش‌فرض: `خدمات`، `فروش`، `خرید`، `اجاره`، `مشارکت`، `نگهداری`، `مشاوره`، `NDA`، `سفارشی`، `سایر`

## 2. فیلدهای پویا (Dynamic Fields / EAV)

### 2.1. قابلیت‌ها
- تعریف فیلدهای سفارشی به ازای هر **نوع قرارداد**
- انواع فیلد پشتیبانی شده: `TextBox`، `Number`، `Decimal`، `Date`، `Boolean`، `Select` (dropdown)، `TextArea`
- قابلیت اجباری کردن فیلدها (`IsRequired`)
- اعتبارسنجی با الگوی Regex دلخواه
- مرتب‌سازی ترتیب نمایش فیلدها (`SortOrder`)
- مقدار پیش‌فرض (`DefaultValue`) و placeholder
- ذخیره و بارگذاری مقادیر فیلدها برای هر قرارداد

### 2.2. سرویس اعتبارسنجی ([`IContractFieldValidator`](Services/Contracts/ContractFieldValidator.cs:8))
- اعتبارسنجی خودکار فیلدهای اجباری
- اعتبارسنجی نوع داده (عدد، اعشار، تاریخ، بولی، گزینه‌های مجاز)
- اعتبارسنجی با الگوی Regex
- بازگشت پیام‌های خطا به صورت Dictionary

## 3. مدیریت مالی

### 3.1. پرداخت‌ها
- ثبت پرداخت با مبلغ، تاریخ، سررسید، روش پرداخت، شماره مرجع
- حذف پرداخت با برگشت سند حسابداری
- وضعیت‌های پرداخت: `Paid`، `Pending`، `Overdue`
- وضعیت کلی پرداخت قرارداد: `Unpaid`، `PartiallyPaid`، `FullyPaid`
- محاسبه خودکار مانده باقی‌مانده و به‌روزرسانی وضعیت پرداخت
- پشتیبانی از ارزهای مختلف در پرداخت

### 3.2. برنامه زمان‌بندی پرداخت (قسط بندی)
- تولید برنامه پرداخت اقساطی برای قرارداد
- تنظیم تعداد اقساط، فاصله روزها، تاریخ شروع
- شخصی‌سازی دستی مبلغ اقساط (Custom mode)
- به‌روزرسانی خودکار وضعیت اقساط سررسید شده (Overdue)
- دریافت و نمایش برنامه در نمای Partial
- حذف برنامه پرداخت

### 3.3. حسابداری تعهدی (Accrual Accounting — [`IContractAccountingService`](Services/Contracts/IContractAccountingService.cs:15))
سه مرحله ثبت سند حسابداری:
1. **افتتاحیه:** بدهکار: دریافتنی / بستانکار: درآمد معوق (Deferred Revenue) — هنگام فعال شدن
2. **دریافت وجه:** بدهکار: بانک/صندوق / بستانکار: دریافتنی — به ازای هر پرداخت (و برگشت هنگام حذف)
3. **شناسایی درآمد:** ماهانه توسط BackgroundJob — به نسبت روزهای سپری شده از قرارداد

### 3.4. ارز چندگانه (Multi-Currency)
- تعریف ارز قرارداد (`IRR`، `USD`، `EUR`، ...)
- نرخ تبدیل به ارز پایه (IRR)
- محاسبه مبلغ پایه برای گزارش‌های مالی
- پشتیبانی از ارز مجزا در پرداخت‌ها و اصلاحیه‌ها

### 3.5. مالیات / VAT
- روش محاسبه مالیات: `Exclusive`، `Inclusive`، `None`
- نرخ مالیات پیش‌فرض (درصد)
- محاسبه خودکار مبلغ کل مالیات و مبلغ نهایی با مالیات
- ردیف‌های مالیات مجزا (`ContractTaxLine`)

### 3.6. شناسایی درآمد (Revenue Recognition)
- رهگیری درآمد شناسایی شده (`RecognizedRevenue`)
- آخرین تاریخ شناسایی درآمد (`LastRevenueRecognitionDate`)
- Backfill برای قراردادهای قدیمی قبل از اضافه شدن قابلیت
- اجرای دسته‌ای برای همه قراردادهای فعال

## 4. ضمانت‌نامه‌ها ([`ContractGuaranteesController`](Controllers/ContractGuaranteesController.cs:11))

### 4.1. انواع ضمانت
8 نوع: `ضمانت‌نامه بانکی`، `کسور وجه تضمین`، `ضمانت شرکت مادر`، `ضمانت حسن اجرا`، `ضمانت پیش‌پرداخت`، `ضمانت گارانتی`، `ضمانت شرکت در مناقصه`، `سایر`

### 4.2. عملیات‌ها
- افزودن، ویرایش و حذف ضمانت‌نامه
- آزادسازی ضمانت‌نامه (`Release`)
- دریافت لیست JSON انواع ضمانت برای dropdown
- بارگذاری lazy در تب Payments صفحه جزئیات

### 4.3. وضعیت‌های ضمانت
`فعال` ← `در شرف انقضا` ← `آزاد شده` / `مطالبه شده` / `منقضی شده`

### 4.4. موتور هشدار و به‌روزرسانی خودکار
- شناسایی ضمانت‌نامه‌های در شرف انقضا (30 روز مانده)
- به‌روزرسانی خودکار وضعیت: Active→Expiring، Expiring→Expired
- رنگی کردن نشان (Badge) بر اساس وضعیت

## 5. اصلاحیه / الحاقیه / تمدید ([`ContractAmendment`](Models/ContractAmendment.cs:10))

### 5.1. انواع
- `Amendment` (اصلاحیه) — `Addendum` (الحاقیه) — `Renewal` (تمدید)

### 5.2. ویژگی‌ها
- تغییر مبلغ (مثبت/منفی) و محاسبه مبلغ جدید
- تغییر تاریخ پایان (تعداد روز) و تاریخ پایان جدید
- تاریخ اثرگذاری اصلاحیه
- پشتیبانی از ارز و نرخ مالیات مجزا
- قابلیت اتصال به درخواست تایید (گردش کار)
- قابلیت اتصال به امضای الکترونیکی

### 5.3. گردش کار وضعیت
`Draft` → `PendingApproval` → `Approved` → `Applied`
`Draft` → `PendingApproval` → `Rejected`
`Draft` → `Cancelled`

- نیاز به تایید (`RequiresApproval`) — قابل تنظیم
- ذخیره نسخه‌ای از قرارداد پس از اعمال (`VersionSnapshotId`)

## 6. امضای الکترونیکی (E-Signature)

### 6.1. امضای داخلی (Internal Signature)
- ثبت امضای داخلی با تصویر Base64
- ذخیره IP، User-Agent، توضیح
- قابلیت بازگشت اطلاعات امضاکننده

### 6.2. امضای خارجی (External Signature — [`IExternalSignatureProvider`](Services/Contracts/ISignatureService.cs:8))
- طراحی توسعه‌پذیر برای ارائه‌دهندگان خارجی (DocuSign، Adobe Sign و ...)
- ایجاد جلسه امضای خارجی با لینک
- بررسی وضعیت جلسه امضا
- تأیید Webhook

### 6.3. فرآیند درخواست امضا
- ایجاد درخواست امضا با عنوان، پیام، روش ارسال (`InApp`، `Email`، `SMS`)
- ترتیب امضا: `Sequential` (ترتیبی) / `Parallel` (همزمان)
- فعال‌سازی خودکار قرارداد پس از تکمیل امضاها
- تولید لینک امضای خارجی برای هر امضاکننده
- نمایش تاریخچه کامل درخواست‌ها با جزئیات امضاکنندگان

## 7. پیوست‌ها و نسخه‌بندی

### 7.1. مدیریت پیوست‌ها
- آپلود فایل با اعتبارسنجی (فرمت، اندازه، magic bytes)
- دانلود فایل با بررسی دسترسی
- حذف فیزیکی و نرم فایل‌های پیوست
- پیش‌نمایش در مرورگر (PDF، تصاویر، متن)
- پشتیبانی از Ajax برای آپلود و حذف

### 7.2. پیش‌نمایش فایل‌ها ([`PreviewAttachment`](Controllers/ContractsController.cs:976))
- PDF: نمایش inline در مرورگر
- تصاویر: نمایش با Content-Type مناسب
- متن: نمایش تا 500KB اول
- انواع ناشناخته: بازگشت پیام "پیش‌نمایش در دسترس نیست"

### 7.3. نسخه‌بندی ([`IAttachmentVersionService`](Services/Contracts/IAttachmentVersionService.cs:8))
- آپلود نسخه جدید از یک فایل پیوست
- نمایش تاریخچه نسخه‌ها با توضیح تغییرات
- دانلود هر نسخه
- بازگردانی نسخه قدیمی (به عنوان نسخه جدید)

### 7.4. پاکسازی پیوست‌های یتیم (Orphan Cleanup)
- شناسایی رکوردهای پیوست بدون فایل فیزیکی
- حذف دسته‌ای (برای مدیران)
